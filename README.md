# Escape（エスケープ）

置き方はドリブルキープと同じで、端末の間隔だけ少し広くする。緑が1台、ほかは赤。緑は敵がいない場所なので、そこへボールを逃がしながらドリブルする。

切り替えは1〜5秒、練習は10秒〜1分。音ありのとき、赤の端末が約0.5秒ブーと鳴る。終わるとコントローラはメニューに戻り、ほかの端末は無色になる。

ローカル確認: `npm test`、`npm run dev`。
